# SKLON
# SKLON — платформа бронирования инструкторских услуг для горнолыжного курорта

**Формат:** клиентский проект  
**Роль:** бизнес-аналитик

## О проекте
SKLON — цифровая платформа для инструкторских школ и горнолыжных курортов. В рамках проекта прорабатывался модуль онлайн-бронирования инструкторских услуг.

## Моя работа
- **Сбор требований:** провела глубинные интервью с пользователями для выявления бизнес-потребностей, проблем и ожиданий от системы.
- **Анализ пользователей:** составила 6 карт эмпатии — для двух клиентских персон, инструктора, администратора, руководителя школы и генерального директора курорта.
- **Моделирование:** разработала 4 CJM для клиента с ребёнком, инструктора, администратора стойки и руководителя школы. 
- **Анализ бизнес-контекста:** исследовала процессы as-is и разработала луковичную диаграмму заинтересованных сторон.
- **Формирование требований:** сформулировала 17 функциональных требований к модулю онлайн-бронирования на основе результатов анализа и ТЗ.
- **Трассируемость требований:** обосновала требования цепочками, связав проблемы пользователей с функциями будущей системы.

## Результаты
- 6 карт эмпатии
- 4 Customer Journey Map
- Луковичная диаграмма заинтересованных сторон
- Анализ текущих бизнес-процессов as-is
- 17 функциональных требований
